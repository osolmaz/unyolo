# Standalone Broker Documentation Archive

This directory preserves every tracked Markdown file from the final local
checkout of the retired standalone broker repositories. The source
repositories are private and archived. BrokerKit is the only maintained source
for broker code and documentation.

not become active instructions for this repository.
